# @dataparbat/theme

DataParbat's console foundation — Foundation v15 token values. Two layers:
`house.css` (constant chrome) + a per-product accent pack (`sendzila.css`
is instantiation #1). Fonts ride along. Consumed by the console and every
product dashboard; the design system that consumes these tokens is
[@dataparbat/ui](https://github.com/dataparbat/dataparbat-ui).
